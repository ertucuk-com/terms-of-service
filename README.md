Hizmetlerimizi kullanırken aşağıdaki şartları kabul etmiş sayılırsınız:

1. Kullanıcı, 13 yaşından büyük olduğunu beyan ve taahhüt eder.
2. Kullanıcı, Discord'un Hizmet Şartları'na uymayı kabul eder.
3. Kötü niyetli kullanım, spam, kötüye kullanım veya botun/hizmetin amacı dışında kullanımı yasaktır.
4. Şirket, herhangi bir zamanda, önceden bildirimde bulunmaksızın, hizmetleri değiştirme, askıya alma veya sonlandırma hakkını saklı tutar.
